Vishwakarma Institute of Technology, Pune

A practical collection of Deep Learning lab assignments covering fundamental neural network concepts, sequence models, convolutional networks, and transfer learning.

This repository contains implementations, experiments, explanations, datasets, and visualizations developed as part of the CI3201: Deep Learning laboratory course.

---

Overview

The lab work progresses from fundamental neural network concepts to more advanced deep learning architectures:

Data Preprocessing → Perceptrons → Neural Networks → RNNs/LSTMs/GRUs → CNNs → Transfer Learning

Each assignment is organized with its corresponding Jupyter Notebook, explanation, datasets, and generated plots where applicable.

Assignment Highlights

Assignment 1 — Data Preprocessing
Introduces TensorFlow/Keras workflows and preprocessing techniques using the Fashion MNIST dataset.

Assignment 2 — Perceptron
Implements a single-layer perceptron from scratch with NumPy to understand the foundations of neural network learning.

Assignment 3 — Forward & Backpropagation
Explores a deep neural network using CIFAR-10 while studying how learning rate and training epochs influence convergence.

Assignment 4 — LSTM Forecasting
Uses an LSTM-based recurrent architecture to model historical Apple stock data and predict future closing prices.

Assignment 5 — Sequence Classification
Compares RNN, LSTM, and GRU architectures for sentiment analysis using the Amazon Alexa Reviews dataset.

Assignment 6 — Custom CNN
Builds a multi-block CNN with data augmentation for classification of mango leaf and fruit pathology images.

Assignment 7 — Transfer Learning
Explores established ImageNet-pretrained architectures including AlexNet, VGG16, ResNet50, and EfficientNetB0.
