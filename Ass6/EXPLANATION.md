# Assignment 6: Custom CNN for Mango Leaf Disease Classification

## 🎯 Objective
Design and implement a Convolutional Neural Network (CNN) for image classification using a unique agricultural dataset (Mango Leaf & Fruit Pathology).

## 🧠 Concepts Covered
- Convolutional layers, strides, and padding.
- Max Pooling and spatial dimensionality reduction.
- Batch Normalization and Dropout for regularization.
- Image Data Augmentation (Rotation, Flipping, Zooming) to prevent overfitting.
- Multi-class classification (6 distinct mango disease/healthy categories).

## 📁 Folder Structure
- `Assignment6.ipynb`: Core implementation notebook.
- `Datasets/`: Folder reserved for local data files.
- `Plots/`: Folder reserved for saving visualizations.
