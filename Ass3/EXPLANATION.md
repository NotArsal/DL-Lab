# Assignment 3: Forward & Backpropagation and Hyperparameter Tuning

## 🎯 Objective
Implement forward propagation and backpropagation using TensorFlow/Keras. Analyze the effect of different learning rates and the number of epochs on model performance using the CIFAR-10 dataset.

## 🧠 Concepts Covered
- Deep Neural Network architecture construction.
- Categorical Cross-Entropy Loss and Softmax activation.
- Systematic testing of learning rates ($\eta = 0.1, 0.01, 0.001, 0.0001$).
- Overfitting detection via varying epoch durations ($10, 25, 50$).
- Evaluation via Confusion Matrix and Classification Reports.

## 📁 Folder Structure
- `Assignment3.ipynb`: Core implementation notebook.
- `Datasets/`: Folder reserved for local data files.
- `Plots/`: Folder reserved for saving visualizations.
