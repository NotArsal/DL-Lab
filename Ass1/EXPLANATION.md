# Assignment 1: TF/Keras Data Preprocessing & Visualization

## 🎯 Objective
Install and configure TensorFlow/Keras. Perform data preprocessing, normalization, train-test splitting, and data visualization on a sample dataset (Fashion MNIST).

## 🧠 Concepts Covered
- Setting up the deep learning environment.
- Loading standard datasets via `tf.keras.datasets`.
- Image pixel normalization (scaling `0-255` to `0.0-1.0`).
- Visualizing image data using Matplotlib.

## 📁 Folder Structure
- `Assignment1.ipynb`: Core implementation notebook.
- `Datasets/`: Folder reserved for local data files.
- `Plots/`: Folder reserved for saving visualizations.
