# Assignment 2: Multilayer Perceptron (MLP)

## 🎯 Objective
Design and implement a Single-Layer/Multi-Layer Perceptron for classification, and evaluate its performance.

## 🧠 Concepts Covered
- Mathematical foundations of Perceptrons ($z = WX + b$).
- Implementing a Perceptron from scratch using NumPy.
- Binary classification of linearly separable datasets.
- Step function and Sigmoid activation functions.

## 📁 Folder Structure
- `Assignment2.ipynb`: Core implementation notebook.
- `Datasets/`: Folder reserved for local data files.
- `Plots/`: Folder reserved for saving visualizations.
