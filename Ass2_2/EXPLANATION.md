# Assignment 2.2: Multilayer Perceptron (MLP)

## 🎯 Objective
Design and implement a **Multilayer Perceptron (MLP)** for multi-class classification on the **Wine Dataset**, evaluated via accuracy metrics and a confusion matrix.

## 🧠 Concepts Covered
- **Deep Feedforward Networks**: Adding hidden layers to bypass the non-linear separability limitations of Single-Layer Perceptrons.
- **Activation Functions**: Using ReLU (Rectified Linear Unit) for non-linear transformations.
- **Data Standardization**: Using `StandardScaler` to normalize input features for stable neural network gradients.
- **Performance Evaluation**: Going beyond raw accuracy by interpreting model predictions through a **Confusion Matrix**.

## 📁 Folder Structure
- `Assignment2_2.ipynb`: Implementation notebook in PyTorch.
- `60_Assignment-2.2_DL.docx`: Submission-ready lab report.
- `Datasets/wine_dataset.csv`: Standardized export of the Sklearn wine dataset.
- `Plots/`: Contains the Loss/Accuracy curve and the Heatmap Confusion Matrix.
